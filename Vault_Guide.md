# Agent Guide: PoE 2 Second Brain

This guide explains the purpose of each directory within the `poe2-vault` workspace to assist agents (and users) in navigating, organizing, and retrieving information efficiently.

## 📂 Directory Structure

### [00_Inbox/](00_Inbox/) - Data Acquisition
A landing zone for raw data, fleeting thoughts, or unsorted files that require processing.
- **[00_Inbox/Quick_Notes.md](00_Inbox/Quick_Notes.md)**: For rapid logging of ideas or reminders during gameplay.
- **[00_Inbox/Unsorted/](00_Inbox/Unsorted/)**: A staging area for raw text files, web summaries, or external data awaiting analysis and relocation.

### [00_Entry/](00_Entry/) - Main Entrance
Contains general introductory documents, project summaries, and master indexes for the vault.

### [01_Builds/](01_Builds/) - Character Build Management
- **[01_Builds/Concepts/](01_Builds/Concepts/)**: Early-stage build ideas and theoretical frameworks.
  - `Build_Template.md`: The standard template for creating new character build logs.
- **[01_Builds/Current/](01_Builds/Current/)**: Active builds currently in use or fully optimized guides.

### [02_Systems/](02_Systems/) - Game Mechanics & Knowledge
- **`Patch_Notes_0.5_Summary.md`**: Key takeaways from the "Return of the Ancients" update.
- **[02_Systems/Core/](02_Systems/Core/)**: Fundamental game mechanics (e.g., Runic Ward, Spirit, Combat systems).
- **[02_Systems/Leagues/](02_Systems/Leagues/)**: Data regarding specific seasonal mechanics and historical league data.

### [03_Assets/](03_Assets/) - Items & Resources
- **[03_Assets/Crafting/](03_Assets/Crafting/)**: Crafting recipes and systems (e.g., Rune Forging, Genesis Tree).
- **[03_Assets/Uniques/](03_Assets/Uniques/)**: Database of unique items and their specific synergies.

### [04_Mapping/](04_Mapping/) - Endgame Systems
- **[04_Mapping/Atlas/](04_Mapping/Atlas/)**: Atlas 2.0 progression, passive tree strategies, and regional data.
- **[04_Mapping/Bosses/](04_Mapping/Bosses/)**: Boss mechanics, encounter strategies, and Fortress (Citadel) data.

### [05_External/](05_External/) - External Resources
- **[05_External/Links/](05_External/Links/)**: Curated links to YouTube, Reddit, Wiki, or Pob.in resources.
- **[05_External/Templates/](05_External/Templates/)**: External templates or snippets adopted for vault use.

### [06_Campaign/](06_Campaign/) - Progression & Leveling
- **`Permanent_Buffs.md`**: Tracking permanent quest rewards (Skill points, Stat buffs).
- **[06_Campaign/Acts/](06_Campaign/Acts/)**: Act-by-act walkthroughs and leveling checklists.

---

## 🔄 Information Management Workflow
1. **Capture**: Place raw info or quick thoughts into the `00_Inbox`.
2. **Process**: Analyze whether the data belongs to a Build, System, Item, or Map category.
3. **Store**: Summarize the data into Markdown format and move it to the appropriate Directory (01-06).
4. **Link**: Create cross-references (wikilinks) between files to build a cohesive Second Brain.
